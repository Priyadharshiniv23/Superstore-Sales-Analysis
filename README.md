# 📊 Superstore Sales & Profit Analysis Dashboard

## 📌 Project Overview
This project presents an interactive **Power BI dashboard** built using the Superstore dataset to analyze sales performance, profitability, regional trends, and product performance. The dashboard provides actionable business insights through dynamic visualizations and KPI metrics, enabling data-driven decision-making.

## 🚀 Features
- Interactive KPI Cards (Total Sales, Total Profit, Total Orders, Profit Margin)
- Sales Analysis by Category and Sub-Category
- Regional Sales Performance
- Monthly Sales Trend Analysis
- Dynamic Filters (Region, Category, Sub-Category, Order Date, Ship Mode)
- Clean and responsive dashboard design

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Fabric
- Power Query
- DAX
- Superstore Dataset

## 📊 Key Insights
- Generated **$2.30M** in total sales across **5,009 orders** with **$286.4K** in total profit.
- Technology emerged as the highest-performing product category.
- West region recorded the highest sales contribution, while South had the lowest.
- Phones and Chairs were the best-performing product sub-categories.
- Monthly sales trends indicated steady business growth over time.
- Interactive filters enable detailed analysis across multiple business dimensions.
